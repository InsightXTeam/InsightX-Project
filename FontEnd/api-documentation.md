# InsightX API Documentation (Report Upload & AI Processing Module)

Welcome to the InsightX Backend API documentation. This document details the routing and endpoints for the **Report Upload and AI Processing Module**, which has been isolated in this branch (`feature/report-upload`).

**Note:** The `[Authorize]` attributes and JWT token validation have been intentionally disabled or mocked on this branch for isolated testing of the Report features. All endpoints will temporarily inject a mock `CompanyId = 1` and `DepartmentId = 1` to simulate an authenticated Manager.

## 🛠️ Endpoints Reference

### 📊 Reports Module (`/api/Reports`)

#### **POST** `/api/Reports/upload`
* **Description:** Uploads a document for AI parsing and metric extraction. Accepts up to 100MB files.
* **Content-Type:** `multipart/form-data`
* **Request Body (`UploadReportDto`):**
  - `file`: The document to upload.
* **Success Response (`200 OK`):**
  Returns details of the newly created report entity, including its ID for status tracking.

#### **GET** `/api/Reports`
* **Description:** Retrieves all reports uploaded by the user's company/department.
* **Success Response (`200 OK`):**
  List of report summary objects.

#### **GET** `/api/Reports/{id}/status`
* **Description:** Tracks the background extraction process (e.g., Pending, Processing, Completed, Failed).
* **Route Parameter:** `id` (integer)
* **Success Response (`200 OK`):**
  Returns an object containing the status enum/string.

#### **GET** `/api/Reports/{id}/preview`
* **Description:** Retrieves the structured JSON of metrics/KPIs extracted by the Semantic Kernel.
* **Route Parameter:** `id` (integer)
* **Success Response (`200 OK`):**
  Returns the raw JSON content generated by the AI models.

#### **GET** `/api/Reports/{id}/text`
* **Description:** Retrieves the raw textual data extracted from the document via OCR or PDF parsers.
* **Route Parameter:** `id` (integer)
* **Success Response (`200 OK`):**
  ```json
  {
    "text": "Extracted text content goes here..."
  }
  ```

#### **POST** `/api/Reports/{id}/confirm`
* **Description:** Confirms the textual extraction and signals the AI processor to begin final KPI metric extraction.
* **Route Parameter:** `id` (integer)
* **Request Body (`ConfirmReportDto`):** Contains any manual text corrections.
* **Success Response (`200 OK`):**
  ```json
  {
    "message": "Text confirmed and KPIs extracted successfully"
  }
  ```

#### **POST** `/api/Reports/{id}/process`
* **Description:** Forces the `DocumentProcessorService` to process the document completely.
* **Route Parameter:** `id` (integer)
* **Success Response (`200 OK`):**
  ```json
  {
    "message": "Processing finished"
  }
  ```

#### **DELETE** `/api/Reports/{id}`
* **Description:** Deletes the report and its associated extracted metrics from the database.
* **Route Parameter:** `id` (integer)
* **Success Response (`204 NoContent`):**
  *(Empty body)*
